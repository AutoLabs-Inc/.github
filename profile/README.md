# AutoLabs

**제조 현장의 품질을 데이터로 기록합니다.**

AutoLabs는 AI와 컴퓨터 비전을 활용해 제조 현장의 검사와 품질 관리를 돕는 기술 기업입니다.

원단 검사를 시작으로 종이·필름처럼 연속으로 생산되는 소재를 다룹니다. 현장에서 이상을 발견하고, 검사 결과를 기록하며, 그 기록을 바탕으로 품질을 판단할 수 있는 제품을 만듭니다.

## 우리가 해결하는 문제

제조 현장에서는 검사를 수행하는 것만큼 그 결과를 남기는 일도 중요합니다.

어떤 제품에서 문제가 발견됐는지, 당시 상태는 어땠는지, 작업자는 어떻게 판단했는지 확인할 수 있어야 합니다. AutoLabs는 현장의 영상과 검사 기록을 연결해 담당자가 품질을 확인하고 설명할 수 있도록 돕습니다.

## AutoBrics

[AutoBrics](https://atlabs.kr/ko/platform)는 현장 검사와 품질 데이터 관리를 연결하는 AutoLabs의 플랫폼입니다.

- **현장 검사:** 촬영 장비와 AI를 결합해 이동하는 소재의 이상을 확인합니다.
- **품질 기록:** 검사 이미지와 발견 위치를 Roll별 이력과 리포트로 연결합니다.
- **데이터 활용:** 검사 정보와 작업자의 판단을 축적해 품질 분석과 검사 개선에 활용할 기반을 만듭니다.

광학 장비, 현장에서 실행하는 AI, 관리 소프트웨어를 함께 개발하며 실제 공장의 작업 방식에 맞춰 제품을 다듬고 있습니다.

## 현장에서 배우고, 제품으로 연결합니다

AutoLabs는 공장을 방문하고 작업자의 검사 과정을 이해하는 데서 출발합니다.

현장의 요구를 기술로 구현하고 실제 환경에서 확인하며, 작업자가 일상적으로 사용할 수 있는 제품으로 발전시키는 것을 중요하게 생각합니다.

국내 제조 현장의 경험을 바탕으로 더 다양한 소재와 생산 환경에 적용할 수 있는 검사 기술을 만들어갑니다.
